# Supplementary artifact release notes, v1.0.5

Version v1.0.5 packages the current 108-study manuscript and the scope-corrected supplementary evidence into a clean submission set.

## Included changes

- synchronized the manuscript and artifact version to v1.0.5;
- retained the 108-study denominator and the validated A-E, family, venue, period, property, and facet summaries from v1.0.4;
- clarified that the 271-to-170 database-identification checkpoint was reproduced from frozen database exports;
- separated licensed database-source exports into a private audit bundle that is not part of the public supplementary ZIP;
- retained the row-level limitation for the combined author-collection and backward-snowballing route;
- added a manuscript-to-artifact map;
- excluded Python cache files and package-construction intermediates from the public archive;
- regenerated file manifests and delivery checksums.

## Unchanged evidence boundaries

- Screening and coding were conducted by one author.
- A-E records the strongest reported verification-evidence category, not proof correctness.
- Published-protocol results are query- and model-specific.
- Family skeletons are modeling examples rather than validated protocol translations.
- Host timings and analytical latency projections are not industrial-device or field-network measurements.

The GitHub repository and tag are updated to v1.0.5. The existing Zenodo
record remains at v1.0.2 and should not be cited as the scope-corrected
v1.0.5 dataset until that archival record is updated separately.
