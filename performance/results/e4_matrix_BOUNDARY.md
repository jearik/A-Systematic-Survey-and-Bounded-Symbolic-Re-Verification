# Corrected Latency Boundary and Namespace

The canonical artifact identifier is **Perf-P1**; the manuscript uses the short
label **P1** for this same performance-only composition. It is distinct from
the published-protocol cases C1=CCAP, C2=CL-BASA, and C3=BCAE.

Perf-P1 uses `message_flights * one_way_latency`, not an RTT-labelled round
count, and has three sequential message flights. Latencies and bandwidths are
assumed inputs; no field-network measurement is claimed.
